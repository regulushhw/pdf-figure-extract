# 范围、标定与交付检查

在 `prepare_task.py` 的 `decisions.json` 设置 `"gate": "scope.json"`，生成带关卡的任务。先从原文与旧件核对下列字段，再运行试读。

命令行的 `build`、`trial` 默认要求范围文件。仅重放历史准备包时才使用 `--legacy-ungated`。

| 字段 | 内容 |
|---|---|
| `pdf_sha256` 与 `pages_reviewed` | PDF 摘要与已经查阅的全部页码，从 1 起。页码声明须来自实际阅读 |
| `inventory` | 一张图或表一个稳定 ID。每项给 `kind`（`figure` 或 `table`）、`page`、`action`（`read`、`transcribe` 或 `exclude`）。纳入项列出 `tables`，排除项写 `reason` |
| `tables` | 预期输出用稳定表 ID 逐项登记。每项给 `sheet`、`range`（数据矩形，如 `B6:L9`）、`columns`、`rows`。紧邻数据的上方是列头，左侧是行标签。同一图的续表分别登记 |
| `baseline` | 旧件只读副本的 `file`、`sha256`、`tables`（同上）。纯说明、原图页用 `metadata_sheets` 按页写原因。首次建表用 `null` 并填 `no_previous_workbook_reason` |
| `cards` | 每个提取部件一个图卡。给 `source`（清单 ID）、按图例顺序的 `series`、`zero`（零基准或不适用理由）、`coordinates` 与 `axes.x/y` |

程序把 PDF 文字层检测到的标题按页码、类型和原文编号与清单核对。清单可用 `label` 明写原文编号，续页填 `continuation_pages`。标题误识别时，用 `caption_false_positives` 记录对应的 `page`、`kind`、`label` 和具体 `reason`。扫描件或识别不到的标题仍在首次逐页查看时登记。

旧数据页的数据区、列头和行标签外如果还有数字、数字文本、日期、公式或缺值标记，机器会列出漏登记的格。确属表注或编号时，在对应旧表项的 `non_data_ranges` 逐区写 `range` 和 `reason`。旧件矩形和新件矩形即使彼此一致，也要先经过这道检查。

每轴填写 `quantity`、`unit`、`kind`、读数器实际使用的 `ticks` 和未参与拟合的 `check_ticks`。刻度对格式为 `[位置, 数值]`。**拟合点和检查点的位置都必须取自原图刻度线**。横轴取刻度线中心的 X，纵轴取刻度线中心的 Y。OCR 数字框中心只用来定位标签，填入配置前要回原图找到对应的刻度线。位置为原图像素时换算系数为 1，PDF 坐标必须依据源图给 `native_px_per_unit`。偏差超过 2 个原图像素时先复看坐标和刻度线。

自动取数使用与图卡相同的线性或对数标定。分类或非规则横轴可用 `manual_points`，把每个印刷标签及其位置记为 `[位置, 标签]`，按图从左到右登记。有刻度线时取刻度线中心，无刻度线的纯分类轴取原图可辨认的分类中心。用独立观察的位置做检查，锚点按同一映射定位。历史版本 1 任务可读取，交付新版工作簿须走新版关卡。

读图表的数据矩形用 `points` 逐格冻结取数对应。例如 `"B6":{"part":"p","id":"s0_x0","role":"value"}`。没有稳定点 ID 的曲线可用 `series` 和 `x` 唯一定位。表内统一舍入时冻结 `decimals`。机器读取当前任务已复核的结果核对写入数值，重名、重复绑定或不同来源的点均会失败。

普通曲线表可用 `"grid":{"part":"p"}` 代替逐格 `points`。程序用冻结的数字列头作采样值、行标签作系列名，按位置展开。文字列头可用 `grid.x` 明确对应的采样值，翻译后的行标签可用 `grid.series` 对应源系列名，次序仍须符合图例。区间端点、异构表或只按像素定位的读数继续用稳定 ID 明确绑定。

开跑前，程序从读数器实际使用的系列选择、采样点或区间角色生成计划位置，和冻结格位逐一对照。遗漏、重复、含糊对应及多余位置均会拦停。新版试读与正式读数覆盖同一冻结范围，复用同一配置可直接复用候选。位图追线以稳定点 ID 绑定，避免把源像素横坐标当成表头数值。尚不能事先列出全部输出位置的读取器不直接用于新版交付。

直接摘录原文数值时将清单项设为 `transcribe`，数据矩形用 `printed` 逐格记录。如 `"B6":{"mode":"text","text":"-12.5%","bbox":[80,110,110,123]}`。坐标是从源 PDF 页面左上起的点坐标。默认使用清单项的页码。续页列入该项的 `continuation_pages`，单元格用 `page` 指明所在页。文字层可用时，程序核对该矩形内实际包含的文字。扫描表用 `mode: "visual"`，并写 `note` 记录该处目读依据。用 PDF 摘要绑定出处。百分号按原文百分数数值保存，例如 `-12.5%` 写成 `-12.5`，单位标为百分数。整篇只摘原表时，可用空图卡集合和工作簿计划通过同一入口。

草稿先对账，通过后生成供一次人工终检的预览。保存时自动复核同一草稿和输出，机器报错时按位置修正。缺值必须在生成草稿之前于任务工作目录的 `delivery_evidence.json` 中按 `工作表!单元格` 绑定 `missing` 记录，含 `kind`（`source_unreadable` 或 `source_uncovered`）、`reason`、`image`、`sha256` 和原图 `bbox`。缺值说明与复核决定一致，位置须落在该点复核范围内。读数时沿用固定入口的源像素审核。机器报错或数据矛盾才回看受影响的位置。

发现写入差错时，修正保存计划里的对应格，再对同一任务运行 `draft`。旧草稿和预览保留，读数与已核实的点位证据接着用。以 `draft` 返回的新草稿路径与预览摘要填写保存确认。旧预览的确认不能用于新草稿。

保存后重新渲染相同视图，由程序逐像素与终检过的预览比较。只有发生变化的视图会单独返回，供局部回看。

也可单独检查旧件和新稿：`python tools/extraction_gate.py scope.json paper.pdf --workbook draft.xlsx --evidence delivery_evidence.json`。

同一准备目录内，按 PDF 与原文图号累计自动失败。固定读数程序出错会登记失败。候选在图上核对失败时，用 `run_task.py TASK reject --part ID --decision REJECTION.json`，决定文件给出 `stage`（`trial` 或 `run`）、当前 `fingerprint`、检查图路径到摘要的 `images` 映射和具体 `note`。同一次候选重复拒绝只算一次。连续两次失败后第三次自动取数被拦截。

转人工时保留同一图卡与取样，使用 `manual_points`，通过与位图取点相同的配置模板或已有复核任务生成待读位置。程序只生成空候选和定位叠图，按现有拖点或批量补点入口录入源像素。空候选仍属于待处理。
